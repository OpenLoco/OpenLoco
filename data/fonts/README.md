# Bundled Unicode fonts

OpenLoco draws Hangul/CJK with `stb_truetype`, preferring fonts already installed
on the system (same idea as OpenRCT2). An optional Galmuri pack can be shipped
for Hangul/kana that matches the 8/10/15px sprite font grid.

| File | Script | License |
| --- | --- | --- |
| `Galmuri7.ttf` / `Galmuri9.ttf` / `Galmuri14.ttf` | Hangul, kana, JP/KR Han (pixel, 8/10/15px) | SIL OFL 1.1, Lee Minseo (`Galmuri-LICENSE.txt`) |

Simplified Chinese and other missing Han glyphs use system fonts (e.g. Malgun /
Yu Gothic / Microsoft YaHei / Hiragino / Noto Sans CJK).
